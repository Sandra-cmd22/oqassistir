# Como Criar a Imagem de Preview (Open Graph)

## 📸 Imagem de Preview para Compartilhamento

Quando você compartilha o link do seu site em **WhatsApp, Instagram, Telegram, Discord ou Twitter**, aparece um preview com:
- **Título**
- **Descrição**  
- **Imagem** ← Você precisa criar esta imagem!

## 🎨 Especificações da Imagem

### Tamanho Recomendado
- **Largura:** 1200 pixels
- **Altura:** 630 pixels
- **Proporção:** 1.91:1 (retangular horizontal)
- **Formato:** PNG ou JPG
- **Tamanho do arquivo:** Máximo 8MB (recomendado: menos de 1MB)

### O que colocar na imagem?
- Logo do CineBuzz
- Texto: "CineBuzz - Descubra os melhores filmes"
- Design atrativo e profissional
- Cores que combinam com o tema do app (#04FFA7, #6416ff, etc.)

## 📁 Como Adicionar

1. **Crie a imagem** com as especificações acima
2. **Salve como:** `og-image.png` ou `og-image.jpg`
3. **Coloque no diretório:** `/public/og-image.png`
4. **Pronto!** A imagem aparecerá automaticamente nos previews

## 🛠️ Ferramentas para Criar

- **Canva:** https://www.canva.com (templates prontos para Open Graph)
- **Figma:** https://www.figma.com
- **Photoshop/GIMP:** Para edição avançada
- **Online:** https://www.bannerbear.com/tools/open-graph-image-generator/

## ✅ Testar o Preview

Depois de adicionar a imagem, teste em:
- **Facebook Debugger:** https://developers.facebook.com/tools/debug/
- **Twitter Card Validator:** https://cards-dev.twitter.com/validator
- **LinkedIn Inspector:** https://www.linkedin.com/post-inspector/

## 📝 Nota

Se você não criar a imagem, o preview ainda funcionará, mas aparecerá **sem imagem**. É altamente recomendado criar uma imagem profissional para melhorar o compartilhamento!
